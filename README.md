## 🎮 What I'm currently building

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>🏭 DAG Factory @ Epic Games</h3>
      <p>A YAML-driven DAG Factory that democratizes Airflow. Analysts with strong SQL but no Airflow chops can now define and ship their own production pipelines through config files — validated by GitHub Actions CI before they hit main.</p>
      <p><b>Stack:</b> Python · Airflow 3 · Astronomer · Pydantic · GitHub Actions</p>
    </td>
    <td width="50%" valign="top">
      <h3>⚡ Databricks Workflow Optimizer</h3>
      <p>Architected pipelines to reuse the same compute cluster across tasks instead of spinning up cold ones per step. Result: <b>70%+ runtime reduction</b> on key recurring jobs feeding Fortnite's monetization analytics.</p>
      <p><b>Stack:</b> Databricks Workflows · PySpark · Unity Catalog · Airflow</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>🧪 Generic SODA Quality Notebook</h3>
      <p>A reusable notebook that lets any team inject robust data-quality checks into any pipeline through a single function call. Co-led from design to platform-wide adoption.</p>
      <p><b>Stack:</b> SODA · Databricks · PySpark · Unity Catalog</p>
    </td>
    <td width="50%" valign="top">
      <h3>🎨 Creator Studio AI <i>(side project)</i></h3>
      <p>Streamlit app that turns a topic prompt into editorial-style Instagram carousels. Claude writes the script, Playwright renders the slides, the user gets a ZIP. Built to scratch my own itch.</p>
      <p><b>Stack:</b> Python · Streamlit · Claude API · Playwright · PIL</p>
    </td>
  </tr>
